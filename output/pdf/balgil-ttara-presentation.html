1. 프로젝트 소개

안녕하세요. 제가 만든 프로젝트는 발길따라라는 국내 여행 코스 추천 서비스입니다. 여행을 갈 때 어디를 가야 할지, 어떤 순서로 이동해야 할지 고민하는 경우가 많아서, 사용자의 조건에 맞춰 하루 여행 코스를 추천해주는 서비스를 만들었습니다.

사용자는 목적지, 여행 테마, 예산, 이동수단, 여행 스타일을 선택할 수 있고, 앱은 그 조건에 맞춰 오전, 점심, 오후, 저녁 순서의 여행 코스를 보여줍니다.

핵심 문제

  • 여행지를 정해도 세부 코스를 짜는 데 시간이 오래 걸립니다.
  • 이동 순서와 소요 시간을 함께 고려하기 어렵습니다.
  • 예산, 취향, 이동수단에 따라 적합한 장소가 달라집니다.

해결 방향

목적지 선택 테마 기반 추천 예산 반영 지도 경로 표시 일정 수정 회원 기능

2. 주요 기능

여행지 선택

서울, 제주, 경주, 부산 등 국내 여행지를 선택하거나 직접 입력할 수 있습니다.

여행 테마 선택

발길따라, 감성따라, SNS따라, 풍경따라, 맛집따라 중 하나를 선택합니다.

조건 기반 코스 생성

도시별 장소 데이터에 테마와 예산 태그를 붙여 조건에 맞는 장소를 고릅니다.

지도와 이동시간

Google Maps API와 Directions API를 사용해 지도 위에 동선과 구간별 시간을 표시합니다.

일정 타임라인

추천 코스를 시간대별 카드로 보여주고, 드래그로 순서를 바꿀 수 있습니다.

회원가입과 로그인

Express API로 계정을 만들고, 비밀번호 해시와 쿠키 기반 토큰으로 로그인 상태를 관리합니다.

3. 구현 구조 설명

프론트엔드

  • App.jsx: 메인 화면, 목적지/테마/예산 선택, 코스 생성, 지도, 일정표를 담당합니다.
  • SignupScreen.jsx: 회원가입 전용 화면입니다.
  • authApi.js: 프론트엔드에서 로그인, 회원가입, 로그아웃 API를 호출하는 파일입니다.
  • index.css: 전체 화면 스타일, 다크모드, 카드 UI, 지도/타임라인 레이아웃을 담당합니다.

백엔드

  • server/app.js: Express 기반 인증 API입니다.
  • server/authStore.js: 사용자 데이터를 읽고 쓰며 비밀번호 해시를 처리합니다.
  • vite.config.js: Vite 개발 서버에 Express API를 미들웨어로 연결합니다.

추천 로직

도시별 장소 데이터에는 시간대, 테마, 예산 정보가 포함되어 있습니다. buildCourse 함수는 사용자가 고른 조건과 필수 방문 키워드를 점수화해서 오전, 점심, 오후, 저녁에 들어갈 장소를 선택합니다.

4. 시연 순서

  1. 메인 화면에서 서비스 이름과 목적을 소개합니다.
  2. 목적지를 선택하거나 직접 입력합니다.
  3. 여행 테마를 선택합니다.
  4. 예산을 선택합니다.
  5. 추천 코스 화면에서 지도, 장소 목록, 상세 정보를 보여줍니다.
  6. 타임라인에서 장소 카드를 이동하거나 새 장소를 추가합니다.
  7. 회원가입 또는 로그인 기능을 설명합니다.
  8. 앞으로의 기획을 발표합니다.

시연 멘트 예시

먼저 사용자는 가고 싶은 국내 여행지를 고릅니다. 이후 여행의 분위기에 맞는 테마와 예산을 선택하면, 앱이 조건에 맞는 장소를 시간대별로 추천합니다.

추천 결과에서는 지도 위에 이동 동선이 표시되고, 각 장소의 추천 이유와 주의사항도 확인할 수 있습니다. 또한 사용자가 직접 일정을 수정할 수 있어서 실제 여행 계획에 맞게 조정할 수 있습니다.

5. 앞으로의 기획

실제 관광 데이터 연동

현재는 직접 구성한 장소 데이터를 사용하지만, 앞으로는 관광지 API나 맛집 API와 연결해 추천 범위를 넓히겠습니다.

날씨 기반 추천

비 오는 날에는 실내 장소, 맑은 날에는 야외 산책 코스를 추천하는 방식으로 개선하겠습니다.

서버 저장 기능

현재 일정표는 localStorage에 저장되지만, 이후에는 사용자 계정별로 서버 DB에 저장하도록 확장하겠습니다.

공유와 협업

친구나 가족과 여행 코스를 공유하고 함께 수정할 수 있는 협업형 여행 플래너로 발전시킬 수 있습니다.

개인화 추천

사용자가 자주 선택하는 테마, 예산, 이동수단을 학습해 다음 여행에서 더 정확한 추천을 제공하겠습니다.

모바일 최적화

실제 여행 중에도 편하게 볼 수 있도록 모바일 화면과 지도 사용성을 더 개선하겠습니다.

마무리 멘트

이 프로젝트는 단순히 여행지를 보여주는 것을 넘어서, 사용자의 취향과 조건을 반영해 실제로 따라갈 수 있는 여행 동선을 만드는 데 초점을 맞췄습니다. 앞으로 데이터를 확장하고 저장, 공유, 개인화 기능을 추가해서 더 실용적인 여행 플래너로 발전시키고 싶습니다.
